# PKI

인증서와 신뢰 체계를 다루는 문서 모음. 신뢰의 근거가 무엇인지에서 시작해, 그것을 발급·검증·갱신하는 방법으로 내려간다.

| 폴더 | 내용 | 상태 |
|---|---|---|
| [certificate/](certificate/README.md) | 세션 1. cert-manager에서 시작해 인증서·인증기관·TLS까지. 도메인 이름 기반의 서버 인증서 | 작성 완료 |
| [mtls/](mtls/README.md) | 세션 2. mTLS, 워크로드 신원(SPIFFE/SPIRE), 서비스 메시 | 개요만 정리. 앞으로 학습하며 채운다 |
| [labs/](labs/README.md) | 실습 계획. DNS-01 검증, 인증서 해부, 주입 경로 비교, 장애 재현 | 계획만 정리. 앞으로 수행한다 |

세션 1은 마무리됐고, 세션 2와 실습은 진행 예정이다. 두 폴더의 README가 다룰 범위와 순서를 먼저 고정해 둔 것이고, 본문은 그 목차를 따라 채운다.

두 세션의 구분은 **식별자를 무엇으로 두는가**다.

| | 세션 1 | 세션 2 |
|---|---|---|
| 식별자 | 도메인 이름 | 워크로드 신원 |
| 신뢰 근거 | 공인 CA, OS·브라우저 신뢰 저장소 | trust domain 내부의 CA |
| 방향 | 단방향 (클라이언트 → 서버 검증) | 양방향 |
